             Objetivo do App:

O objetivo do aplicativo Hotel Acordess é calcular de forma simples e rápida o valor total da hospedagem com base em critérios como:

Quantidade de adultos e crianças

Tipo de suíte escolhida

Período da estadia (check-in e check-out)

Ele facilita a simulação de preços para clientes e também pode ser útil para uso interno do hotel.


           Linguagem utilizada:

O app foi desenvolvido utilizando .NET MAUI (Multi-platform App UI), com as linguagens C# (para a lógica) e XAML (para a interface gráfica).
